새 보스 추가

웹 관리자·마스터·운영진이 날짜별 참여 체크박스를 공통으로 관리합니다. 이 목록은 출현 타이머와 독립적이며, 모든 회원에게 똑같이 표시됩니다. 기존 참여 기록은 삭제하지 않습니다.

자동 계산 버튼은 선택 날짜의 가장 빠른 출현 시간을 기준으로 해당 주 일요일까지 주기를 생성합니다. 이전 날짜와 다른 주는 유지합니다. 컷을 누르면 지난 출현 체크박스는 유지하고 미래 체크박스만 컷 시각 기준으로 교체합니다. 수동 수정 시 해당 날짜만 고정됩니다. 이후 보스 컷·점검·시간 재설정으로 이 날짜의 체크박스가 다시 늘어나지 않습니다. 삭제된 시간의 기존 참여 데이터는 보존하지만 해당 시간의 점수는 현재 주간 계산에서 제외됩니다.
